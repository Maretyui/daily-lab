062 — CSS Paint Worklet Pattern

The dot grid is drawn entirely by a registered CSS Paint Worklet (Houdini), not a background-image or SVG — it reads the element's own custom properties (spacing, color) at paint time, so a live CSS variable change or hover state redraws it directly, no JS re-render or repaint call needed. Falls back to a static radial-gradient grid in browsers without Paint API support (Firefox, Safari as of this writing).
