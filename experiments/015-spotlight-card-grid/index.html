Spotlight card grid

Move your cursor over any card below — a soft teal radial glow tracks the pointer inside that card only, both as a subtle fill and as a glowing 1px border edge. No canvas, no JS animation loop: just two CSS custom properties updated on pointermove and a couple of pseudo-elements doing the rendering.

Real-time sync

Changes propagate to every connected client in under 50ms.

Offline-first

Works fully disconnected, then reconciles on reconnect.

Typed end-to-end

Shared types between client and server, no drift.

Edge-deployed

Runs close to the user on every continent by default.

Zero-config auth

Session handling that just works out of the box.

Composable

Small primitives that combine instead of one big framework.

Each .card listens for its own pointermove and computes the cursor's position relative to that card's bounding box (getBoundingClientRect()), then writes it to two inline custom properties, --x and --y. A ::before pseudo-element paints a radial-gradient centered on those coordinates as a soft fill; a ::after pseudo-element paints the same gradient again but clipped to a 1px ring via a mask-composite: exclude trick (subtract the content-box from the full box, leaving only the border strip) so it reads as a glowing edge instead of a fill. Both fade in and out purely via CSS opacity transitions on :hover — the JS never touches visibility, only position.
