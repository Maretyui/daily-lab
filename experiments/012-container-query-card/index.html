Container query card

The same card markup below reflows from a stacked layout to a side-by-side layout purely based on its own container's width — not the viewport. Click a width preset to see it happen with no JS involved in the layout decision at all.

Maretyui

Web design & swim instruction — this box reflows on its own width, at any viewport size.

A media query only ever knows about the viewport, so a component that needs to look different depending on how much space its parent gives it — a sidebar widget vs. the same widget in a full-width main column — traditionally needed JS (a ResizeObserver) to fake this. container-type: inline-size on the wrapper opts it into containment, and @container card-frame (min-width: 360px) queries that wrapper's own box directly. The card component itself has zero idea what viewport it's on; it only reacts to the box it's actually sitting in, which is what makes it genuinely reusable in a sidebar, a modal, or a grid column without separate breakpoint logic for each placement.
