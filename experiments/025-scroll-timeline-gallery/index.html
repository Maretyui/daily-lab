Scroll-driven view timeline gallery

Every card below fades, un-blurs and slides into place purely from CSS - no IntersectionObserver, no scroll event listener, not a single line of JavaScript. It's built on the CSS animation-timeline: view() and animation-range properties: instead of a timeline driven by time, the animation's progress is driven directly by how far each card has scrolled through the viewport. The browser handles it on the compositor thread, so it stays smooth even on a very long page.

Your browser doesn't support scroll-driven animations (animation-timeline: view()) yet - the cards below will just appear instantly instead of animating in. This is a progressive-enhancement technique: nothing breaks without it.
