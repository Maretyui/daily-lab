navigator.getGamepads() returns a fresh snapshot on every call instead of a live object, and only inside a loop you drive yourself — there's no gamepadinput event, so this page re-reads it on every requestAnimationFrame tick while a pad is connected. Button values are read as button.value (0–1) rather than just .pressed, so analog triggers (L2/R2) fade in gradually instead of snapping straight to full.
