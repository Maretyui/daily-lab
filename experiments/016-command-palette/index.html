Command palette

A ⌘K-style fuzzy command launcher built on the native <dialog> element — showModal() handles the backdrop, focus trapping, and Escape-to-close, so the only custom logic left is filtering the list and moving the "active" row with the arrow keys.

    Press Ctrl/⌘ + K anywhere on this page, or click the button above. The command list lives as a plain JS array; every keystroke re-filters it with a case-insensitive substring match against each command's label, and ↑/↓ move a highlighted "active" index that wraps around at either end. Enter "runs" the active command (here, just an alert) and closes the dialog via dialog.close(); clicking anywhere on the ::backdrop also dismisses it for free, since that's native <dialog> behavior once method="dialog"-style light-dismiss is wired to a backdrop click listener.
