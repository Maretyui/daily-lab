074 — @scope Style Isolation

.card-scoped contains a nested .note widget, and both reuse the same generic class names (.label, .value). The card's colors are set with @scope (.card-scoped) to (.note), so the scope stops right at the nested widget's boundary — the note stays untouched even though it's a DOM descendant of the card. The button below shows the same markup styled the "old" way, with a plain descendant selector that has no boundary and bleeds into the nested widget.

Your browser doesn't support @scope — the scoped card below will render unstyled since this demo intentionally has no JS fallback for it.
