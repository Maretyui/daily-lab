145 — LCS Word Diff

Edit either side and the comparison below rebuilds as you type. Nothing is guessed line by line — the longest common subsequence of the two word lists decides what counts as kept, and everything off that path is an insertion or a deletion.

Splitting on whitespace turns both texts into token lists, and a classic (n+1) × (m+1) dynamic-programming table fills in the length of the longest common subsequence of every pair of prefixes. Walking that table backwards from the bottom-right corner replays the single alignment it found: diagonal steps are words both versions share, sideways steps are words only one of them has.

Word-level rather than line-level is what makes a reworded sentence readable — a line differ would mark the whole paragraph as replaced, because every character after the first edit sits on a changed line. The table is quadratic in token count, so input here is capped; real differs switch to Myers' algorithm, which walks the edit graph's diagonals instead of filling the whole grid.
