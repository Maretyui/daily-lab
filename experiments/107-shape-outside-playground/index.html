107 — Shape Outside Playground

The pink shape is a plain floated <div> — the paragraph wraps to its actual outline, not its rectangular box, because shape-outside redraws the float's wrap boundary from a CSS shape function instead of its bounding box.

Before shape-outside, wrapping text around anything but a rectangle meant slicing a paragraph into manually sized spans — one per line — and hand-tuning each width to fake a curve. The property instead lets the browser itself compute, line by line, where the shape's edge actually falls and reflow the text to that boundary, live, as the shape, its size or its position changes. Drag the controls above: the box stays a plain rectangle in the DOM the whole time, only its wrap boundary and its own clip-path outline change, and every line of this paragraph reflows instantly to match. On a triangle the available width shrinks line by line toward the point; on the wave it oscillates in and out with every ripple. It's just CSS — no JavaScript line-measuring, no canvas, no masked overlay image.

shape-outside only affects text flow around the float — it draws no visuals itself, which is why this demo also sets a matching clip-path on the same element purely so the shape is visible. The two properties accept the same basic-shape syntax (circle(), ellipse(), polygon()), so one set of coordinates, written once per shape here, drives both at once.
