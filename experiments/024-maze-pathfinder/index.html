Maze generator + A* pathfinder

A perfect maze (exactly one path between any two cells, no loops) is carved with a randomized depth-first backtracker, then solved live with the A* search algorithm using Manhattan distance as the heuristic. Frontier and visited cells are drawn as the search actually explores them, so you can watch A*'s heuristic pull it toward the goal instead of exploring blindly like a breadth-first flood fill would.
