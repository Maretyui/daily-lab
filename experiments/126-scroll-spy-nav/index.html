126 — Scroll Spy Nav

The pill row below tracks which section is in view as you scroll and highlights it automatically — no scroll event listener, just an IntersectionObserver watching each section's top band.

Intro History How it works Trade-offs More

Intro

Scroll down through these panels on a phone or with a mouse wheel. Watch the pill above highlight itself as each section crosses into the "active band" near the top of the viewport.

History

Scroll spies used to be built by listening to scroll events and manually comparing getBoundingClientRect() against the viewport on every frame — cheap-looking code that was actually a layout-thrashing performance trap.

How it works

Each section is observed with a root margin that shrinks the detection zone to a thin band near the top: rootMargin: "-15% 0px -70% 0px". Whichever section's top edge is inside that band when it fires gets the active class.

Trade-offs

Clicking a pill still needs to set the active class itself for the instant between the click and the scroll settling, since the observer only reports entries as they cross the threshold, not on jump-to.

More

The same observer instance watches all five sections — one observer, five targets, no per-section listeners to clean up.

Built with a single IntersectionObserver whose rootMargin turns the viewport into a thin horizontal detection band near the top. Pill clicks scroll via scrollIntoView({ behavior: "smooth", block: "start" }) and set the active class immediately so the UI doesn't lag behind the click while the smooth scroll is still animating.
