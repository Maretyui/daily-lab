075 — Share Card

A single share button that calls the real navigator.share() API when the browser and context (HTTPS, a real user gesture) support it, and falls back to copying the link to the clipboard everywhere else — desktop Chrome/Firefox included, since they don't implement navigator.share() at all as of this writing.

Scroll-Timeline Progress

A page-progress bar and section reveals driven entirely by CSS animation-timeline — no scroll listener, no IntersectionObserver.
