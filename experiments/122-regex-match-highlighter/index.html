122 — Regex Match Highlighter

Type a pattern and some text; every match gets highlighted live as you type, with capture groups outlined separately. Nothing leaves the page — it's just RegExp and matchAll() re-run on each keystroke.

    Matches are found with pattern.matchAll(text) (the g flag is added automatically under the hood if you forget it, since matchAll requires it) and rendered by splicing <mark> elements around each match's index/length — text content only, no innerHTML from user input, so nothing typed here can inject markup.
