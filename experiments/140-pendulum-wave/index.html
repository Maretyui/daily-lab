140 — Pendulum Wave

Fifteen pendulums released together, each a hair shorter than the last so it swings a little faster. No synchronization logic — the wave, the standing-still moment, and the mirrored wave are just what the phases do on their own. Tap the stage to release them all again.

Cycle: 0% Resyncs: 0
Pendulum i gets length tuned so it completes exactly (N + i) full swings in one shared period T — each one's angle is just θ·cos(ωi·t). Every bob starts in phase, drifts apart because the periods differ by a fixed fraction, and lines back up exactly at t = T. No per-frame coupling between pendulums at all, just N independent clocks.
