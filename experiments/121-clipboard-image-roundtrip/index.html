navigator.clipboard.write() takes a ClipboardItem built from the canvas's own toBlob() output, and navigator.clipboard.read() hands back the same kind of blob to decode with createImageBitmap() — both skip ever turning the pixels into a text data URL. Writing needs no permission prompt from a click handler; reading may ask for clipboard-read permission the first time.
