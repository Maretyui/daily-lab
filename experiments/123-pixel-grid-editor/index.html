123 — Pixel Grid Editor

A 20×20 tile grid you paint by tapping or dragging a finger/pointer across it — each tile is filled as a flat-shaded square, not a free-hand stroke, so the result stays crisp at any zoom. Export it as a real PNG.

The canvas is drawn at a fixed 20×20 tile resolution internally; pointer coordinates are converted from CSS pixels back to canvas space with canvas.width / rect.width before picking a tile, so painting lines up correctly whether the board is shown at its natural size or scaled down to fit a narrow screen. pointerdown/pointermove (not HTML5 drag-and-drop) drive the painting, so it works the same with a mouse, a stylus, or a finger.
