078 — interpolate-size Accordion

Toggling <details> normally snaps between height: 0 and height: auto with no animation, because auto has never been an interpolatable value. Setting interpolate-size: allow-keywords once on :root lets the browser compute a real intrinsic size for auto and transition into it smoothly — the CSS below has no JS-measured pixel height anywhere.

What is interpolate-size?

A CSS property that opts keyword sizing values like auto, fit-content, and min-content into being animatable, by having the browser resolve them to a used pixel value it can then transition to and from.

Why not just measure scrollHeight in JS?

That's the usual workaround, and it still works everywhere — but it means re-measuring on every content or font change, and re-running the measurement on resize. This property makes the whole class of workaround unnecessary for browsers that support it.

What happens without support?

The panel still opens and closes correctly — it just snaps instantly instead of transitioning, exactly like the pre-existing default behavior. Nothing breaks, it only loses the animation.

The shared name="acc" attribute is the newer exclusive-accordion behavior for native <details> elements — opening one automatically closes the others in the same group, also with zero JS.
