Ratio is (L1 + 0.05) / (L2 + 0.05), where L1/L2 are each color's relative luminance (WCAG 2.x's own formula: gamma-decode each sRGB channel, then weight R/G/B 0.2126 / 0.7152 / 0.0722) and L1 is always the lighter of the two — same math browsers and design tools use, run here on every keystroke or color-picker drag.
