081 — @starting-style Filtered List

Filtering a list normally means items just snap in and out. Here every add/remove animates via the CSS @starting-style at-rule — no JS-driven class juggling, no setTimeout to "wait for the animation to finish" before hiding an element.

Part of daily-lab. Browser support: Chromium and Firefox 129+; Safari does not yet support @starting-style (the list still filters correctly, just without the transition).
