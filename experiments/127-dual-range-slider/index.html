127 — Dual Range Slider

Two native <input type="range"> elements stacked on the same track, each pushing the other out of the way so the handles never cross — a min/max price-filter pattern built from nothing but native sliders.

Min 20
Max 80
0100
Both inputs share one invisible track; CSS makes everything but the round thumb pointer-events: none so a touch always lands on exactly one handle. JS clamps each input so dragging either one pushes the other by at least 1, then repaints the .fill bar's left/right from both values as plain percentages.
