113 — Geo Distance Tracker

Tracks real movement with the Geolocation API's watchPosition, summing great-circle distance between consecutive fixes with the haversine formula and plotting the walked path on a canvas — no map tiles, just the raw lat/lon trail rescaled to fit.

Needs location permission — works best outdoors with a clear GPS fix.

Each new fix is only accepted if coords.accuracy is under 50m, so a noisy indoor Wi-Fi-based position can't fake a sprint. The canvas path is just the raw lat/lon points linearly rescaled to the canvas box — it has no projection and will distort at low latitudes over long distances, same as any flat approximation of a sphere.
