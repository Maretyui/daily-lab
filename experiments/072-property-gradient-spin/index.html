@property

Typed custom properties, animated natively

The conic-gradient's rotation (--angle) and inner color stop (--stop) are both registered via @property with a real <angle>/<percentage> syntax. That's what makes them animatable by the browser's own interpolation in a @keyframes block — an un-registered custom property can only ever jump between values, never tween through them. No JS, no repainting per frame; hover or focus the card to pause both animations via animation-play-state.
