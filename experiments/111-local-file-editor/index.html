111 — Local File Editor

Open a real .txt file from disk, edit it, and save your changes straight back into that same file — no download link, no re-picking a save location each time.

Checking browser support…

Uses the File System Access API — showOpenFilePicker() and showSaveFilePicker() hand back a FileSystemFileHandle that a createWritable() stream can write to directly, so "Save" updates the original file in place instead of producing a new download each time. Where the API isn't available (Firefox, Safari, most mobile browsers) the editor stays disabled with an explanation instead of silently doing nothing.
