Popover toast stack

Every toast below is its own native popover="manual" element — rendered straight into the browser's top layer, so it's always painted above everything on the page with zero z-index bookkeeping. Entry and exit animate through @starting-style plus transition-behavior: allow-discrete, which lets a display: none element transition in and out instead of snapping instantly.

Each click creates a fresh <div popover="manual">, appends it to the document, and calls .showPopover(). Using manual rather than the default auto value matters here: an auto popover closes any other auto popover the moment a new one opens, which is exactly right for a menu but wrong for a notification stack — manual popovers are independent, so several can stay open side by side. Every toast still gets Escape-to-dismiss and light-dismiss for free from the API; this demo also layers on its own auto-dismiss timer, a hover-to-pause progress bar, and a real close button.

Removal is driven by the popover's own toggle event rather than a guessed timeout: calling hidePopover() starts the CSS exit transition (thanks to allow-discrete on display/overlay), and once the browser reports event.newState === "closed" the element is actually removed from the DOM and the remaining toasts smoothly reflow upward via a plain top transition recalculated on every add/remove.
