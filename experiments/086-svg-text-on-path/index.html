SVG text on a draggable path

The text is a normal <text> element with a <textPath> child pointing at a <path> by id — the browser lays out and re-flows every glyph along that curve on its own. Dragging the teal handle only ever rewrites the path's d attribute (a single quadratic Bézier); the text reroutes itself with no per-character math on this end.
