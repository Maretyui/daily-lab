120 — Picture-in-Picture Timer

A plain stopwatch that also works when the tab is in the background. "Pop out" moves the live timer and its controls into a real floating always-on-top window via the Document Picture-in-Picture API, so it stays visible while you switch tabs or apps. Everything below still works as a normal on-page stopwatch if that API isn't there.

00:00.0
Ready.
Uses window.documentPictureInPicture.requestWindow(), which hands back a second real Window with its own document — elements get moved into it (not cloned), so the exact same buttons and listeners keep working inside the floating window. Closing that window or clicking "Pop out" again moves everything back here. Support is desktop Chrome/Edge only for now; the stopwatch itself runs everywhere, the button just disables when the API is missing.
