Drag to reorder

Native HTML5 drag-and-drop, no library. Grab an item by its handle and drag it up or down — a teal edge highlight on the item under your cursor shows exactly where it will land before you let go, and the item you're dragging fades to 35% opacity in place while it moves.

The mechanics are four events on each <li draggable="true">: dragstart records which element is moving and adds the faded .dragging class; dragover (which must call preventDefault() or the browser refuses to allow a drop at all) compares the cursor's vertical position against the hovered item's own midpoint to decide whether the drop indicator belongs above or below it; drop actually moves the dragged node in the DOM via insertBefore/ insertAdjacentElement; and dragend clears every visual state regardless of whether the drop landed on a valid target, since the browser doesn't guarantee drop fires on a cancelled drag.
