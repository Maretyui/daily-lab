101 — MIDI Note Visualizer

Play the on-screen keys with mouse or finger, or plug in a MIDI keyboard — every note-on lights up its key and adds a rising bar to the roll above, in real time.

Checking for Web MIDI…
Falls back to a plain clickable/touchable keyboard everywhere. Where navigator.requestMIDIAccess() is supported (Chrome/Edge, not Firefox or iOS Safari) and a device is connected, its noteon/noteoff messages drive the same visualizer and synth as the on-screen keys.
