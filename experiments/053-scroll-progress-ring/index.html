Scroll Progress Ring

A conic-gradient ring that fills as you scroll the page — zero JavaScript, zero scroll event listeners. It's a single CSS animation whose animation-timeline is set to scroll(root) instead of the usual wall-clock time, so the browser itself drives --pct from 0% to 100% in lockstep with document scroll progress. Keep scrolling to watch it complete.

Section one

The ring updates continuously as the compositor scrolls this page — no scroll event, no requestAnimationFrame, no re-render.

Section two

Because the timeline is driven by the scroll container itself, this stays perfectly smooth even under heavy main-thread work that would normally cause a JS-based scroll progress bar to lag or jank.

Section three

@property --pct registers the custom property as an animatable <percentage>, which is what lets the browser interpolate it smoothly inside the conic-gradient() instead of snapping between keyframe values.

Section four

Support: Chrome/Edge 115+ and Firefox 129+ implement scroll-driven animations natively. Safari doesn't yet — the ring simply stays static there, which is an acceptable fallback for a decorative progress indicator.

The end

The ring should now read as fully filled. Scroll back up to watch it drain in reverse — the timeline works both ways for free.
