082 — text-wrap: pretty vs balance

Drag any panel's own resize handle (bottom-right corner) narrower and watch how each wrapping mode avoids ugly single-word orphan lines — or doesn't. No JS measures anything here; it's three CSS keywords.

text-wrap: wrap (default)

Custom Highlight API Search Demo

Greedy line-breaking fills each line as full as possible, which often leaves a short orphan word dangling alone on the last line.

text-wrap: balance

Custom Highlight API Search Demo

Balances line lengths evenly across a block. Great for headings, but browsers cap it around 4 lines — not meant for body copy.

text-wrap: pretty

Custom Highlight API Search Demo

Slower, paragraph-aware algorithm that specifically avoids orphans on the final line, with no line-count limit — the better default for body text.

Part of daily-lab. Browser support: Chromium 117+ for balance, Chromium 130+ and Firefox 141+ for pretty; Safari supports neither yet and silently falls back to normal wrapping.
