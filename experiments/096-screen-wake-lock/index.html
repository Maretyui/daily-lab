096 — Screen Wake Lock

Toggle the lock and leave your phone alone — the screen stays on (and the dial keeps pulsing) instead of dimming and locking on its usual timeout.

Wake lock is off.
Uses the Screen Wake Lock API (navigator.wakeLock.request('screen')). The lock is automatically released by the browser whenever the tab is hidden (switching apps, locking the phone manually, minimizing) — this page listens for that and re-requests it once the tab becomes visible again, which is the documented way to handle it rather than a one-time request.
