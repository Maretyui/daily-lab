createMediaElementSource(audio) taps the element's output into an AnalyserNode, which has to be routed back to audioContext.destination explicitly — tapping it otherwise silently replaces normal playback instead of just listening in on it. The AudioContext itself is only created on the first file pick/play, since browsers block it from starting before a user gesture.
