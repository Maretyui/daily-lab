Zero-JS tooltip via CSS anchor positioning

Hover the button below. The tooltip that appears above it is tethered with pure CSS — no getBoundingClientRect(), no resize listener, no library. The button declares anchor-name: --tip-anchor; the tooltip references it with position-anchor and position-area: top, and the browser keeps it pinned on scroll and resize automatically.

Anchored above, zero JS

Before CSS anchor positioning, tethering a floating element to a trigger meant either a positioning library (Floating UI, Popper) or hand-rolled JS re-measuring both elements on every scroll/resize event. Here the tooltip is just a position: fixed element pointed at the button's anchor-name — the browser's layout engine does the tethering math natively, so it never drifts out of sync even during fast scrolling.

Support: Chromium 125+ only as of 2026 — Firefox and Safari haven't shipped it yet. Without support the tooltip still works as a position: fixed box, it just won't stay attached to the button if the page scrolls; worth feature-detecting with CSS.supports("anchor-name: --x") before relying on this for anything load-bearing.
