063 — Resizable Split Pane

Drag the divider to resize. Pointer events capture the drag so the cursor can leave the divider without breaking the resize, and the column width is clamped so neither pane can be dragged to zero.

Left pane Width is driven by a single CSS custom property (--left) on the grid container, updated on pointermove. No layout library, just grid-template-columns.
Right pane Try dragging past either edge — the width is clamped between 15% and 85% so both panes stay usable. Arrow keys also work while the divider has focus.
