094 — Voice Notepad

Tap the mic and start talking — the browser's speech recognizer transcribes it live into the notepad below. The transcript stays editable at any time, dictated or not.

Tap the mic to start dictating.
Uses the SpeechRecognition API in continuous + interim-results mode. Finalized phrases get appended to the textarea; the still-being-recognized phrase shows separately above it until it's finalized or corrected. Browser support is inconsistent — this works in Chrome/Edge and most Chromium-based mobile browsers, but not in Firefox or desktop Safari.
