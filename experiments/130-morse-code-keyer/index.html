130 — Morse Code Keyer

Type text to see it in Morse, or type dots and dashes to see them decoded back to text. Then try keying it by hand: hold the button for a dot or a dash, and pause to let a letter or a word resolve on its own — same as the translator above, but timed by touch instead of typed.

Current letter  
Decoded
 
A press under 250ms is a dot, anything longer is a dash. Releasing and pausing for 600ms resolves the held dots/dashes into a letter; pausing 1.4s adds a word space. A single GainNode gates one continuously-running oscillator so the beep starts and stops instantly with no per-press audio node allocation, and touch-action: none on the button stops the hold-press from also trying to scroll the page on a phone.
