109 — IndexedDB Scratchpad

A tiny multi-note scratchpad backed by IndexedDB instead of localStorage — notes survive a reload (try it), and because reads and writes are transactional, nothing is lost even if a write and a page close race each other.

    indexedDB.open() returns immediately with a request object, not a database — every call here waits for its own onsuccess, and every read/write happens inside a db.transaction(['notes'], mode) object store, not directly against the database. Typing debounces a put() by 400ms so every keystroke doesn't open its own transaction, but switching notes or closing the tab flushes immediately first.
