089 — Lasso Multi-Select

Drag anywhere on the empty grid background to draw a rubber-band selection box — every tile it overlaps gets selected live as you drag. Tap a single tile to toggle it on its own. Works identically with a mouse or a finger, all driven by Pointer Events.

0 selected
Selection state lives in a Set of tile indices; the lasso rectangle is recomputed on every pointermove by comparing its bounds against each tile's getBoundingClientRect().
