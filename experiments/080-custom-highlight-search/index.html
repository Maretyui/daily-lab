080 — Custom Highlight API Search

Typing below highlights every match inside the passage using the CSS Custom Highlight API — Range objects are registered into a Highlight and styled entirely through the ::highlight() pseudo, with no wrapper <mark> elements injected into the DOM and no layout reflow from mutating text nodes.

The CSS Custom Highlight API lets script-driven text ranges be styled without touching the document tree at all. Traditional search-highlighting wraps every match in a span or mark element, which mutates the DOM, can split existing elements awkwardly, and has to be carefully undone when the search term changes. A Highlight object instead holds a live list of Range instances, registered once via CSS.highlights.set, and the browser paints them directly during layout. Clearing a search is just deleting the ranges, not diffing DOM nodes back to their original shape.
