144 — Two-Axis Sticky Table

Scroll the grid below in both directions. Toggle each axis off to see which labels you lose track of first — no JavaScript keeps anything in place, it is four position: sticky rules and a z-index order.

position: sticky resolves against the nearest scrollable ancestor, so putting the overflow on a wrapper instead of the page is what makes a frozen header possible at all — and keeps a wide table from pushing the whole document sideways on a phone.

The corner cell is the interesting case: it is sticky on both axes simultaneously and overlaps both frozen bands, so it needs a higher z-index than either. Leave that out and it scrolls underneath the row labels, stacking two pieces of text on top of each other. The dividing lines are inset box-shadows rather than borders, because a collapsed border belongs to the table grid rather than the frozen cell and detaches from it mid-scroll.
