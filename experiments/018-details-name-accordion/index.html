Exclusive native accordion

Give a group of <details> elements the same name attribute and the browser turns them into an accordion on its own: opening one closes any other member of the group, exactly like radio inputs sharing a name. No JavaScript, no ARIA wiring, no listening for toggle events to close siblings by hand - the browser already knows they're mutually exclusive.

Grouped with name="faq" - opening one closes the rest

What actually links these together?

Just <details name="faq"> on each element in the group. That's the entire mechanism - the same attribute, repeated.

Does this need any JavaScript?

None. The exclusivity is implemented by the browser's own HTML parser/rendering engine, the same layer that already handles <details>/<summary> toggling and radio button groups.

What if a browser doesn't support grouping?

It degrades gracefully: the name attribute is simply ignored and every <details> behaves independently, same as it always has. Nothing breaks, you just lose the exclusivity until that browser catches up.

Both can stay open together - that's the default, un-grouped behavior.

One quirk worth knowing: if two grouped <details> both start with the open attribute, the browser has to pick a winner at parse time - only the first one actually renders open, and the rest are force-closed even though their markup says otherwise. Only mark one element per group open to begin with.
