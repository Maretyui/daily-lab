Animated gradient border via @property

The rotating rainbow border below is a plain conic-gradient() background on a wrapper element, sized 3px bigger than its inner card so only the edge shows. What makes it spin smoothly is @property: it registers --angle as a real <angle> custom property instead of an untyped string, so the browser knows how to interpolate it between keyframes — the gradient's from angle animates continuously instead of jumping.

@property --angle

syntax: "<angle>", animates 0deg → 360deg

Before @property, animating a custom property used in a gradient just didn't work — CSS treated it as an opaque string, so @keyframes couldn't tween it at all; you'd need a JS requestAnimationFrame loop writing the angle every frame instead. Registering the property's syntax turns it into a typed value the animation engine actually understands, so this now runs entirely on the compositor.

Support: Chromium 85+, Firefox 128+, Safari 16.4+ — solid baseline as of 2026. Without support, the card just renders with a static 0deg gradient instead of spinning — no layout breakage.
