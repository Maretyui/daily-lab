116 — Diamond-Square Terrain

A midpoint-displacement heightmap: start with four random corners, then repeatedly fill in square and diamond midpoints as the average of their neighbors plus shrinking random noise, halving the grid step each pass until every cell has a height.

Rauheit
Heights get normalized to 0–1 after generation, then mapped to a water/sand/grass/rock/snow palette by threshold. The Rauheit slider controls how fast the random offset's scale decays each pass (scale *= 2^-roughness) — low values smooth into rolling hills, high values stay jagged all the way down to single-pixel noise.
